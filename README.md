# Win11
## Windows-style Quick Settings & Notification Center

A Quick Settings shortcut (gear / notification glyph) is added to the taskbar. It opens a Windows-inspired control panel with Wi-Fi and Bluetooth settings, Location, ring modes, display/rotation settings, volume controls, Airplane Mode settings, flashlight toggle, Power Popup (requires enabling the app's Accessibility service), and a recent-notifications list (up to 60 entries while the notification listener is active).

Android security restrictions apply: Wi-Fi/Bluetooth/Location/Airplane Mode and rotation controls open the relevant system settings rather than silently changing protected system state. Screen recording and screenshots require Android's system screen-capture consent; the panel explains how to use the built-in Android controls and does not capture other apps silently. Flashlight brightness control is supported on Android 13+ devices that expose torch strength; older devices use on/off.
